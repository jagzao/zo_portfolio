# Component Measurements

## Reference viewport
- Desktop reference: 1440–1600px wide
- Content max width: 1280px
- Mobile breakpoint target: 390px reference

## Layout
- Desktop outer padding: 32–48px
- Section vertical gap: 80–112px
- Card gap: 18–24px
- Card padding: 22–28px
- Hero content max width: 760px
- Hero Architecture Lab teaser: 380–480px wide

## Radius
- Button: 10–12px
- Standard card: 16–18px
- Premium panel: 22–24px

## Type
- H1 desktop: 54–68px
- H1 mobile: 38–46px
- Section H2: 32–42px
- Body: 16–18px
- Metadata: 12–14px
- Technical labels: Fira Code 11–13px

## Accessibility
- Touch target >=44px
- Body contrast >= WCAG AA
- Focus ring visible in gold or red with sufficient contrast
- No information encoded by color only

## Effects
- Gold glow is restrained and local.
- Red is for active/action/exception emphasis.
- Avoid permanent glow around every card.
