- [ ] Identity is understandable in <=5 seconds.
- [ ] Positioning visible: .NET, Node.js, Distributed Systems & Applied AI.
- [ ] Proof/credibility appears before deep technology exploration.
- [ ] Primary CTA is obvious.
- [ ] No technology wall in hero.

## Brand
- [ ] Black base matches approved board.
- [ ] Gold is primary premium accent.
- [ ] Red is controlled action/emphasis accent.
- [ ] UI does not look like generic SaaS.
- [ ] UI does not look like gaming/cyberpunk.
- [ ] Typography remains highly readable.

## Pages
- [ ] Home matches hierarchy.
- [ ] Case Studies separates enterprise work and own products.
- [ ] Wondernails public story includes multi-tenant + RAG/agent capability accurately.
- [ ] Zo Media Intelligence appears with approved tagline.
- [ ] Experience is scannable without clicks.
- [ ] Technical Arsenal graph is interactive and accessible.
- [ ] Architecture Lab graph is impressive but understandable.

## Security/content
- [ ] No PRIVATE_INTERNAL_PROJECTS identifiers anywhere.
- [ ] No internal/private identifiers in assets/metadata.
- [ ] Second-brain is not written to.

## Evidence
- [ ] desktop screenshots
- [ ] mobile screenshots
- [ ] reduced-motion screenshots/state
- [ ] side-by-side board comparison
- [ ] 0 BLOCKER/HIGH visual drift
